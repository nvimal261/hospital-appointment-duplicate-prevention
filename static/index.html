💡 Decision Explanations & Fallback Inspector

Rule-based decision catalog and human-readable explanation inspector for non-specialists.

Catalog of Explanation Rules

CONFIRMED (SLOT_AVAILABLE)

"Appointment confirmed because the requested slot was available."

IDEMPOTENT (IDEMPOTENT_RETRY_MATCH)

"This request was already processed. The existing appointment was returned instead of creating another record."

SLOT CONFLICT (SLOT_ALREADY_BOOKED)

"The requested doctor/time slot is already booked."

CONCURRENCY CONFLICT (RACE_CONDITION_PREVENTED)

"Another request reserved this slot first. This request was rejected to prevent double booking."

TRANSACTION FAILURE (TRANSACTION_ROLLED_BACK)

"The appointment could not be safely completed. No inconsistent booking was created."

Fallback Suggestions Workflow

When a booking is rejected due to a conflict, the system suggests alternate available slots:

  • Choose an alternative time for the requested doctor
  • Choose an alternate doctor available on the same date
  • Retry the request with a fresh key if appropriate
  • Contact hospital reception staff
